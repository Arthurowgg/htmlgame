GRAND PIXEL GAMELUMINA ISLE · LAUNCHER 3.1

Install a standalone pixel launcher that downloads the game for you and opens it in its own app window.

Windows

  1. Install Python 3 (tick “Add to PATH”)
  2. Download the setup script and run it
curl -LO https://raw.githubusercontent.com/Arthurowgg/htmlgame/arena/01a08cbd-htmlgame/setup/GPG_Setup.py
py GPG_Setup.py

Linux / macOS

curl -LO https://raw.githubusercontent.com/Arthurowgg/htmlgame/arena/01a08cbd-htmlgame/setup/GPG_Setup.py
python3 GPG_Setup.py
Download GPG_Setup.py Play Lumina Isle in browser Dev game source
