STANDALONE DESKTOP APP · NOT A WEB LAUNCHER

GRAND PIXEL GAMEPIXEL LAUNCHER 3.0

The launcher is a real desktop application with a pixel-art UI — version picker, install library, profile, and play — inspired by the Minecraft launcher. It is not this HTML page.

From the repository root:

# setup once
python3 -m venv .venv
.venv/bin/pip install pygame pillow pyinstaller

# run the launcher
.venv/bin/python launcher/run.py

Or build a single executable:

.venv/bin/python launcher/build_exe.py
# → launcher/dist/GrandPixelGameLauncher
Play game source directly Play v2.0.0
